Set-up explains rule packs in plain words: they are Rerail's standard rules, mostly the ones linters use, checked while the coding agent writes rather than after, with your linter and CI left as they are. Suggesting packs says it looks at what a repo is built with, not at how its code is written. Run from a coding agent, the sessions question names the session the person is in, and says Rerail checks the agent's work, not them. The dashboard's Create a rule page says the same about packs, and `/rerail-create`'s menu entry now says it can also suggest rules for the repo.
