Edits an agent makes in a Git worktree of a started repository, with its file tools or in a shell, are audited and appear in the dashboard, whichever folder the session started in. They used to go unaudited unless a session had started in that worktree. A worktree with its own stopped value stays stopped. What Rerail could not check in another worktree shows as a gap in the session's record, as it does in the session's own folder.
