Rule packs can give each rule `dimensions` in `pack.json`: what it guards against (security, data safety, availability, correctness, performance, maintainability or test quality), where its code lives and how badly a violation can go. A pack's page in the dashboard filters by risk and shows each rule's risk and severity; `GET /api/rule-packs` returns them. Such a pack needs Rerail 0.2.2.
