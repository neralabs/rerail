Code rules can read C, C++, C#, Go, HTML, CSS, Markdown and JSON by syntax: `language: "c"`, `"cpp"`, `"csharp"`, `"go"`, `"html"`, `"css"`, `"markdown"` or `"json"`. `.h` files are C++. As for Java, names, values, arguments, calls and format arguments are not read for them yet; for JSON a rule that uses one is refused.
