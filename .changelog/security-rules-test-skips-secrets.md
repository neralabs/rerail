`rerail rules test` no longer reads hidden files, files named like secrets (`.env*`, `*.pem`, `id_rsa*`, `credentials`, `credentials.*`, `credentials-*`/`credentials_*` data files, `.ssh/` and the like), symlinks, checkouts nested in the repository, or files Git ignores when it checks a draft against the repository, so their lines never reach the coding agent. Ignored files are read only after the repository's Follow .gitignore is turned off in the dashboard or through `/api`, the pass refuses in a Git checkout whose ignore rules it cannot read, and the report counts what it left out.
