A daemon whose `--tls-key` other accounts can read (on Windows any account besides you, SYSTEM and Administrators, as under `C:\certs`) serves this computer alone, over plain http on loopback: Windows served others, macOS and Linux refused. `rerail daemon start` then exits 1 if it asked for `--allow-remote` or `--public-host`. A missing, unreadable or non-key file still stops it.
