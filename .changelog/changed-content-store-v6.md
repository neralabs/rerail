The content store's file is now `content-v6.sqlite`, with what it keeps in files in the folders beside it: the names and strings (`.atoms`), which every Rerail process reads in place, the facts (`.frames`, `.memo`, `.facts`), and the tapes and sources (`.objects`). Names and strings are stored once each, and running several policies over one repository keeps each one's work. The old `content-v1.sqlite` (with its `-wal` and `-shm`) is no longer read and is safe to delete.
