`rerail support-bundle` writes one file of Rerail's diagnostics to attach to an issue, since a dashboard link only opens on the reporter's computer: versions, Rerail's state, rule ids and modes, a session's timeline by event kind and tool name, its steers, its violations by rule and line, and the end of the daemon's log. Prompts, replies, tool input and output, source code and rule text stay out, known secrets and paths are replaced, and the command sends nothing. `/rerail-bug-report` works out what went wrong from that file: an engine bug or a bug in a rule that ships with Rerail, which it offers to report in an issue after checking the file with you, or a bug in your own rule, which it helps you fix. The README and the bug and rule misfire forms ask for it in place of a session link.
