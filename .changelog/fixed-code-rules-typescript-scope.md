Code rules resolve TypeScript names more as typescript-eslint's scope manager does. The head of a qualified type name (`foo` in `let x: foo.Foo`) reads only types, so it resolves to an import, namespace, enum or class of that name and never to a parameter or variable that is only a value. A member declared with `declare` directly inside a `declare module` body (`declare module 'm' { declare const x: string; }`) counts as used.
