Every internal-testing feature is now off until its variable is set, `rerail scan` included. `RERAIL_EXPERIMENTAL=1` turns them all on, or `RERAIL_EXPERIMENTAL_<FEATURE>=1` one, set for the process that runs it; a running daemon is restarted with it. A CI job that runs `rerail scan` sets `RERAIL_EXPERIMENTAL_HEADLESS_SCAN=1`. [Internal testing](docs/internal-testing.md) lists each feature and its variable.
