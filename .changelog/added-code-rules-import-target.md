Code rules read JavaScript and TypeScript modules as eslint-plugin-n does: `importTarget` matches a module specifier by how it is imported, its kind, and whether it resolves, is a Node builtin or is a declared dependency; `languageOptions.moduleSystem: "package-type"` takes each file's module system from its nearest `package.json`; and `file.package` and `file.byteOrderMark` read a file's package and byte-order mark ([DSL reference](docs/code-rule-dsl-reference.html#importTarget)).
