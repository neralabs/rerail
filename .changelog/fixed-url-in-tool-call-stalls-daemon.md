On Windows, a URL written with `//` and any scheme but `file:` or `smb:` in a coding agent's tool call (`curl https://example.com/api`) no longer stalls the Rerail daemon, which answered no hook in any session for about 21 seconds when the URL's host did not answer. A path with doubled backslashes (`"C:\\Users\\me"` in JSON) is now checked as `C:\Users\me` is.
