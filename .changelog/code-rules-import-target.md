`importTarget` matches a JavaScript or TypeScript module specifier as eslint-plugin-n reads it: `via` (`import` or `require`), `moduleType` (relative, absolute, node, npm, http or data), and whether the target is a Node builtin, resolves, spells its extension, is published, is a declared or dev dependency, or is aliased. `file.package.private` and `file.package.published` match by the nearest `package.json`.
