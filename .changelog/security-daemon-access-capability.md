Every request to the daemon, its API, `/mcp`, `/healthz` and the hooks' engine socket included, needs its access capability (the `x-rerail-access` header, from `daemon.json`) and gets `401` without it, so another user or a sandboxed process that reaches localhost gets nothing. Open the dashboard with `rerail manage`; a bookmark no longer gets in ([troubleshooting](docs/troubleshooting.md#the-dashboard-says-needs-the-dashboard-link)).
