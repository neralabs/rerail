6. The decisions

Where does the walk decide a removed worktree's files are no edits?

We chose a look for the .git entry after Git answered, at first sight or where a file is gone.

Would change our mind: A removed worktree's deletions recorded in Log through a real daemon: on Linux Git can delete the .git entry after the look.
