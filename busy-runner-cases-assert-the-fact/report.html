6. The decisions

How does a case show that the move reads no row past the step?

We chose the helper counts the rows and the text the reads of audits return, and each case asserts its exact count.

Would change our mind: A better-sqlite3 build with SQLite's statement counters, which would count the rows SQLite reads, those it does not return included.

What does the scrubber's case time, so that load does not read as growth?

We chose equal work on both sides: four quarter-megabyte passes against one megabyte pass, alternating, the fastest turn of each.

Would change our mind: A counted fact for the scan's work, which V8's regular expression engine does not give.
