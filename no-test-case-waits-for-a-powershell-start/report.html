6. The decisions

Where should the PowerShell start happen, so no helper case's limit holds it?

We chose in the set-up of a describe block that holds only the cases that need it, one per file, kept open.

Would change our mind: A vitest hook bound that cannot be set per hook, or a way to change a token's privileges from Node without a child process.

8. What is not covered

  • macOS and Linux both helpers' PowerShell cases run only on Windows; the four changed test files ran on Linux x64; macOS never ran.
  • A first start past 120 s fails the set-up once and skips the block's cases. A first start here took 425 to 456 ms; the bound rests on the 32.8 s seen on GitHub's runner.
  • The privileges' states the case that reads them skips where the token holds neither, as on the machine these runs used; it runs on GitHub's Windows runner.
  • A policy set through group policy outranks the process's own: where one sets AllSigned or Restricted, the host steps' three cases still fail. No machine here had one.
