5. The changes

  • Low risk Opens past main-only includes: A linked worktree whose main checkout's include loops: main refuses it; here it opens, as Git does.

6. The decisions

Open again with includes off in every linked worktree, or only the user's own?

We chose only where the user owns the repository: elsewhere the open would skip an included safe.directory that empties the list.

Would change our mind: A gix option that reads safe.directory with includes while the repository's own includes stay off.
