6. The decisions

How does the holder make its pipe without waiting on the machine's modules?

We chose it calls .NET only, so Windows PowerShell looks up no module.

Would change our mind: A machine whose PowerShell runs in Constrained Language Mode, which refuses .NET's static methods; it refuses Add-Type too.
