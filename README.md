# Screenshots and design reference for the dashboard pull request

Sample data only. Open the HTML file in a browser: the dark bar at the top is a viewer for sample states and is not part of the design.

- `1-overview-one-banner-added-and-edited.png`: Overview, one banner for the rules a coding agent added and the edits it made.
- `2-review-next-rule-opens-its-sheet.png`: Review next rule opens the next waiting rule's sheet, with where it stands, Approve and steer, and Delete rule.
- `3-approved-offers-the-next-rule.png`: after Approve, the sheet stays on the rule and offers the next one.
- `4-original-says-an-edit-waits.png`: an edited rule on its pack's page: Edited on its row, and its sheet says an edit waits, with Review the edit.
- `5-edit-waits-for-approval-light.png`, `6-edit-waits-for-approval-dark.png`: the edit's own sheet, with what changed, Approve and steer, and Discard edit.
- `7-add-rule-packs-cards-default.png`: Add rule packs opens on Cards.
- `rerail-dashboard-design-reference.html`: the dashboard on sample data with the design notes. The states "Rules wait for approval" and "A pack rule was edited" show this change.
