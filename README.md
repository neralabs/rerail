# Rerail

Rerail is a local semantic monitor for AI-augmented engineering teams. It inspects live human, model, and tool
activity outside the generative model, detects when that activity is semantically close to shared engineering
context, and surfaces the relevant guidance at the moment it matters.

> Status: pre-release. The code is being moved into this repository and nothing is published yet.

## Repositories

- `rerail` (this repository): the core package, published to npm.
- [`rerail-fixtures`](https://github.com/neralabs/rerail-fixtures): language conformance test data, checked out
  here as the `fixtures/` git submodule. Clone with `git clone --recurse-submodules`.
