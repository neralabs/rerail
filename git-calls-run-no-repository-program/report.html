6. The decisions

How should a call keep a repository's drivers from running?

We chose list the config with its scopes, then set each driver a repository defines to the person's value or none.

Would change our mind: a repository whose rules need its own driver's output in Rerail's diff.

8. What is not covered

  • macOS never ran.
  • Git LFS on Linux never ran; on Windows 11 it cleans as the person's own Git does.
  • A Git older than 2.31 ran through stand-ins on Linux only, not through the built command line.
  • The stand-in Git cases run on Linux only: Windows cannot start a script as its Git.
Three limits that stay

Limits that stay.

  • A writer changing the config between the listing and the call has its driver started in some calls: 9 of 40 audits on Linux.
  • A checkout of more than about four million files that records a submodule passes the listing's cap and fails the diff.
  • Submodules more than 16 deep fail the diff, where Git follows them.
