Duplicate Block Explorer

Duplicated blocks in Jeff's tree, found by five suffix-array methods over lines and format 16 tape nodes, merged by file and grouped into clone classes.

How to use this page
  1. Pick a scope below: Jeff's native/src Rust, or his src, test and packs.
  2. Read the diagram. It is a Venn diagram for five sets, drawn as columns. Each column is one exact intersection: the clone classes found by the methods with a filled dot, and by none of the others. The bar is how many classes that is. The bars beside the method names are each method's total.
  3. Filter. Click a method's name to require it, again to exclude it, again to leave it open. Click a column to show exactly that intersection. Columns drawn in blue are the ones the list shows; the sentence under the diagram says the same in words.
  4. Pick a class in the list. The table shows, for each copy, the block each method reported there (its lines, its units, and the other places it named), or that it did not find it.
  5. Compare two copies under the table. Lines are aligned by their text; changed lines and tokens are tinted, the coloured bars in the gutter show which methods covered each line, and lines Jeff's rule does not count are dimmed.
  6. Show dropped noise brings back the blocks post-processing removed, with the reason. The Methods tab shows each method at work on a small example, and Speed compares the runs.
