# Licences of the eslint test data

This archive is the test data of `packs/javascript/upstream/eslint/`. `provenance.json` beside this file lists every file in it with its source, its upstream path and how it was made. Each upstream source below is listed with its licence, how many files come from it, and its licence text as the repository tracks it under `packs/javascript/licenses/`; the rest is Rerail's.

## eslint

Repository https://github.com/eslint/eslint, tag `v10.11.0`, commit `3c0b7c6e1fe2dec778b97a996018126f22d437ae`. License: MIT.

19078 file(s): 10344 extracted, 8734 renamed. They remain under eslint's licence. Files marked `extracted`, `adapted` or `renamed` were changed by Rerail as `provenance.json` describes: `extracted` is one test case cut out of the upstream file it names (`detail` locates the case), `adapted` is such a case wrapped so the tool reads it, and `renamed` is the file `renamedFrom` names with its names renamed (literals and the names' order kept). `verbatim` files are unchanged copies.
