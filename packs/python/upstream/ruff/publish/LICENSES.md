# Licences of the ruff test data

This archive is the test data of `packs/python/upstream/ruff/`. `provenance.json` beside this file lists every file in it with its source, its upstream path and how it was made. Each upstream source below is listed with its licence, how many files come from it, and its licence text as the repository tracks it under `packs/python/licenses/`; the rest is Rerail's.

## ruff

Repository https://github.com/astral-sh/ruff, tag `0.16.9`, commit `0be08a206f9c3180afd3e93bcc792ed5cb1f4db1`. License: MIT.

938 file(s): 938 verbatim. They remain under ruff's licence. Files marked `extracted`, `adapted` or `renamed` were changed by Rerail as `provenance.json` describes: `extracted` is one test case cut out of the upstream file it names (`detail` locates the case), `adapted` is such a case wrapped so the tool reads it, and `renamed` is the file `renamedFrom` names with its names and literals renamed. `verbatim` files are unchanged copies.
