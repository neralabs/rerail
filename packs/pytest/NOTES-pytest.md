# pytest pack: mining notes

What a full-stack Python team's reviewers send back on test code, checked against the linters it already runs. The
pack's rules are about tests that pass without checking what they claim (a mock the code never calls, mocks swapped
between parameters) and tests that interfere with each other (state a test changes and never restores). Ruff's PT
family (flake8-pytest-style), PGH005 and B003 are ported in the `python` pack; nothing here repeats them.

All corpus numbers below come from probes run on 2026-11-24 over the test files (a `tests`, `test`, `unittests` or
`testing` directory, `test_*.py`, `*_test.py`, `tests.py`, `conftest.py`) of the 20 repositories in
`~/rerail-bench/python-arch/corpus/MANIFEST.tsv` (8,977 files): a Python `ast` walk per candidate, then each hit read
in the repository. They size a candidate; the rule writers' corpus runs of the finished rules are the evidence.

## 3. Build list, ranked

1. `pytest-practice-patch-misses-from-import`: silent wrong result (the code under test runs the real function: real
   e-mail, real HTTP, `assert_not_called` always passes); cross-file.
2. `pytest-practice-patch-decorator-order`: silent wrong result (asserts on the wrong mock); 4/4 real in the corpus.
3. `pytest-practice-scoped-fixture-mutated`: test pollution through a shared fixture value; cross-file (conftest).
4. `pytest-practice-django-settings-in-test`: Django settings leaking between tests, stale caches; framework-aware,
   the test-side half of `django-practice-settings-runtime-assignment`.
5. `pytest-practice-environ-without-monkeypatch`: environment leaking between tests (and into subprocesses).
6. `pytest-practice-module-state-without-monkeypatch`: module globals and class attributes leaking between tests;
   cross-file.
7. `pytest-practice-yield-fixture-unsafe-setup`: teardown skipped when setup fails half-way (log).
8. `pytest-practice-sleep-in-test`: slow, flaky tests (log).

Rules 4–6 are three rules, not one, because their remedies differ (`settings` fixture or `override_settings`,
`monkeypatch.setenv`, `monkeypatch.setattr`) and their noise differs; each is measured and given its mode on its own.
