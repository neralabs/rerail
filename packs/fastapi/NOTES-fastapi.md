# FastAPI pack: mining notes

What the `fastapi-practice-*` rules are built on: the sources read, every candidate weighed, and the build list. The
corpus is the shared one (`~/rerail-bench/python-arch/corpus/MANIFEST.tsv`); for this pack three FastAPI repositories
were added to it, because the seven in the shared set are modern, well-kept apps that had already moved off several of
the patterns below:

| Repository | Commit | .py files | Why added |
|---|---|--:|---|
| `zenml-io/zenml` | `61569b1e08e71372c37effd94f7e1f17da4140c4` | 2,518 | a large FastAPI server on a sync SQLModel session |
| `Buuntu/fastapi-react` | `af17f2d422d0ebc5f173e83f2c6931045ab055b0` | 30 | the classic cookiecutter layout: `async def` routes on a sync `SessionLocal()` dependency |
| `letta-ai/letta` (tag 0.16.8) | `1131535716e8a31c9a437f8695e25ac98f203a24` | 878 | 252 `async def` routes, per-call HTTP clients, `on_event` helpers |

The `python` pack (`packs/python/pack.json`) was checked for every candidate: it ports Ruff's FAST001-003, ASYNC100,
105, 115, 116, 210, 221, 222, 230, 250, 251, B008 and RUF006, and Bandit (B113 request without timeout among them).
The sibling packs' boundaries (BRIEF.md and their lead specs) decide the rest: `python-practice` owns blocking calls
reached from any `async def` through helpers (requests, `time.sleep`, `open`, subprocess); `sqlalchemy` owns engines
created per request, `AsyncSession` shared between tasks and lazy loads under asyncio; `python-security` owns request
data flowing into sinks. This pack takes what only FastAPI's own semantics settle: which functions FastAPI runs per
request and where (routes, dependencies, middleware), what a `Depends` hands them, when a yield dependency's exit code
runs, which routes a router serves, and what the response model lets out.

Coordinator's decision on the split with python-practice: `python-practice-blocking-call-reached-from-async` reports
framework-free blocking calls (`time.sleep`, sync requests/httpx, urlopen, subprocess, `os.system`, sockets, sync file
IO) reached from any `async def`, FastAPI routes included. This pack builds no generic blocking-call rule; it keeps the
FastAPI-specific shapes: a sync SQLAlchemy session or sync DB dependency used from an async route (directly or through
helpers), the yield-dependency and BackgroundTasks session lifecycle, response models, auth and lifespan.
