# Rewrite registry (INVARIANTS I4)

Owner: S1. The logical side lives in `rerail-facts`; S2 implements the physical side.

SQLite version (I1, decider's ruling 2026-10-23): "SQLite semantics" means the SQLite the native engine bundles, **3.53.2** (rusqlite 0.40.2, `bundled`); every differential test against SQLite runs that library. The Python oracle's SQLite (3.51) defines findings parity only, not stage semantics (it differs, e.g. on the `UNION` representative).

Every rewrite takes the algebra (`ir::Rel`, or a resolved pattern query before it becomes a leaf), never SQL text or a name. A row lands here with:

- its side conditions, checked in code;
- its justification;
- its differential test;
- its mutant.

Mutants are `crate::mutant::on(n)` at the rewrite's site, behind the `mutants` feature. Run one with `FACTS_MUTANT=<n> cargo test -p rerail-facts --features mutants --lib`. The gate parses the `mutant` column, cell format `<n> <kind>`.

Numbers:

- 1–3: the physical matcher (R12, R13 below; `spikes/facts-a/src/lowered.rs`), re-seeded from S2's interim A3 views (wave 3); read by the gate's registry parser from the facts-a table (family `facts-a-unit`, `a-unrewritten`);
- 4–6: S3's delta generator;
- 7: classifier;
- 8: planner audit (inner scans);
- 9: S3's runtime tie detection (windows and `LIMIT` not provably total; a tie between distinct rows is a runtime refusal);
- 10: order proofs (`classify::KeyEnv::total`: every order taken as proven total; killed by `classify::tests::order_marks_proven_and_checked`);
- 11 upward: rewrites (R6–R11: 16–21);
- 22: the spike SQL engine's derived-table scoping (`sql/engine.rs::Planner::source_schema`, S6b; not a rewrite: the gate's `MUTANTS`, family `facts-a-unit`, `a-vs-reference`);
- 23: R14 (facts-a table);
- 24: R15 (facts-b table: S3's delta generator, family `facts-b-unit`, `b-generated`);
- 25, 26: R16, R17 (facts-a table, S8);
- 31, 33: the spike SQL engine's SQLite 3.53.2 rulings (c) bare columns (`Planner::select`'s refusal check) and (d) compound column types (`walk_arms`); not rewrites: the gate's `MUTANTS`, family `facts-a-unit` (S8c).
- 27: R18, 29: R19 (facts-a table, S8b; S8b takes odd numbers from 27, S3-5 even from 28);
- 28–40 (even): R20–R32, the delta generator's decorrelation rewrites (facts-b table); 44: R34 (same table); 48: R36 (same table, S3-6);
- 42: the generator's ordered aggregates (`group_concat`/`json_group_array` folded in the order of the Sort below; not a rewrite: the gate's `MUTANTS`, family `facts-b-unit`); 46: the generator's LEFT JOIN on equalities (unmatched rows by an antijoin on the join's keys, stratified inside a recursion; `MUTANTS`, `facts-b-unit`).
