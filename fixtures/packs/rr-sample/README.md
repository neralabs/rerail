# rr-sample

A fixture pack whose rules are written in `.rerail` (test/engine/catalog/packs.test.ts): `rr-sample-assert` is one file,
`rr-sample-print-call` includes the pack's own library file, `rules/lib/sample-calls.rerail`, and
`rr-sample-deprecated-call` reports a call for what another file says of the function it calls.
