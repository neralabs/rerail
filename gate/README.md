# gate

Ledgers the engine's tests derive and compare: each file is what the engine computes today, and a test fails when the
two differ. Re-bless a ledger only with the change that moves it, and review its diff.

| Path | What it records | Checked by | Bless with |
|---|---|---|---|
| `data-layer/census/` | the data-layer rules' constructs, clauses and recursions in Rerail logic (`recursion.tsv` is written by hand) | `logic::front::data_layer_census_tests` | `RERAIL_BLESS_CENSUS=1` |
| `data-layer/final-shape/` | the ServerPlan quality rule as an `.rerail` program, generated by `logic/gen.py` from `template.rerail` | `logic::rr::tests::rr_programs_print_as_themselves` | `python3 gate/data-layer/final-shape/logic/gen.py` |
| `executor-coverage/` | where each executor probe ran, or why not (`matrix.tsv`), and each pack's gaps (`packs.tsv`) | `logic::plan::coverage` | `RERAIL_BLESS_COVERAGE=1` |

The data-layer port's recordings and rule corpus these tests also read are pack test data, not in git:
`npm run fixtures:pull` puts them under `packs/data-layer/upstream/lint/authored/` (packs/data-layer/upstream/lint/UPSTREAM.md).
